

•	Rocket League
	•	Engine Used: Unreal Engine
	•	Details: Developed by Psyonix, Rocket League leverages Unreal Engine’s capabilities for high-quality 3D graphics and smooth multiplayer gameplay. Unreal’s networking features and strong physics engine were ideal for Rocket League’s fast-paced, physics-based gameplay.
	•	Raft
	•	Engine Used: Unity
	•	Details: Raft was created by Redbeet Interactive using Unity, which is popular for indie titles. Unity’s flexibility for both 2D and 3D games allowed Raft to blend survival mechanics with a stylized 3D environment. Unity’s support for cross-platform releases and easy asset integration also contributed to Raft’s development and success.
